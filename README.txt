NARESH FAGERIA - ACCOUNTANT PORTFOLIO
======================================

1. Copy this entire folder into your XAMPP htdocs folder.

Windows XAMPP:
    C:\xampp\htdocs\Naresh_Fageria_Accountant_Portfolio

Mac XAMPP:
    /Applications/XAMPP/xamppfiles/htdocs/Naresh_Fageria_Accountant_Portfolio

2. Start Apache in XAMPP.

3. Open in browser:

    http://localhost/Naresh_Fageria_Accountant_Portfolio/

Pages:
    /index.php
    /about.php
    /skills.php
    /certifications.php
    /contact.php

Files included:
    - Dynamic PHP configuration
    - Premium black/gold responsive design
    - Tally certificate PDF
    - Resume PDF
    - Certificate viewer
    - Resume link
    - Mobile navigation
    - Responsive CSS
    - JavaScript interactions

OPTIONAL PROFILE PHOTO:
Put Naresh's photo at:
    assets/images/naresh_image.png

The portfolio will automatically show the photo.
If no photo exists, it shows "NF".

IMPORTANT:
The portfolio data is centralized in:
    includes/config.php

Edit that file if you need to change the name, phone, email,
skills, education, certificate, resume path, or portfolio URL.
